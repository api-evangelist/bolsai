# bolsai

Brazilian financial-market data API — B3 stocks (ações), real-estate funds (FIIs), fundamentals, dividends, financial statements, and macro series. Data sourced from official providers B3, CVM, and BCB (Brazil's central bank).

## APIs

- **bolsai REST API** — Brazilian financial-market data REST API covering companies, stocks, screener, fundamentals, financial statements, dividends, FIIs, and macro series. Authenticated via X-API-Key header. (`https://api.usebolsai.com/api/v1`)

> REST API base https://api.usebolsai.com/api/v1 with X-API-Key auth (confirmed). Docs label the OpenAPI download as Postman-importable but no separate Postman collection URL is published. The MCP server (bolsai-mcp) is a LOCAL/stdio package run via 'uvx bolsai-mcp' or pip; it is NOT a hosted public endpoint, so it is not cataloged as an MCP property. It exposes 10 tools and calls the bolsai REST API. llms.txt URL is advertised/declared but its body was not independently verified during research. No AsyncAPI or GraphQL contract found; CSV export via ?format=csv on most endpoints.
